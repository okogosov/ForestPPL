ForestPPL is continue of project Forest.

What's new:

1.New ScopeManager to provide access to variables within functions, loops, and other block statements.

2.New Producer-Consumer mechanism for efficient processing of commands entered via the console or read from files.

3.Significantly improved performance through AST traversal enhancements.

4.New Storage implementation supporting jagged arrays, plus the addition of the StorageLib library.

5.Pre-execution syntax error detection using the `checksyntax` command.

6.Improved diagnostics and bug fixes.

7.Removed limitations regarding array index calculation and function parameter passing.

8.Modified API for working with external libraries.

9.Added VS Code support.

10.Added HTML-format reference documentation.
