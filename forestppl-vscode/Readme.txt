Enhance your ForestPPL development experience by enabling custom syntax highlighting in Visual Studio Code. 
You can easily add the official syntax rules to your editor using the provided extension package.
Installing the ForestPPL Extension via UI
•	Open Visual Studio Code.
•	Navigate to the Extensions view by clicking the square icon in the Activity Bar on the left side of the window (or press Ctrl+Shift+X).
•	Click the Views and More Actions menu (the three dots ... located at the top right corner of the Extensions panel).
•	Select Install from VSIX... from the dropdown menu.
•	Locate and select the VS.Code\forestppl-vscode-0.3.0.vsix file on your local machine, then click Install.
•	Restart VS Code if prompted.
Alternative Installation via Command Line If you prefer using the terminal, 
you can install the extension directly by running the following command in the folder where your file is located:
code --install-extension VS.Code\forestppl-vscode-0.3.0.vsix
Once the installation is complete, Visual Studio Code will automatically recognize your ForestPPL script files. 
The editor will apply the dedicated color scheme and syntax highlighting to your commands, keywords, and variables, 
making it significantly easier to read, navigate, and debug your code.
